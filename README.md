# OCEAN LORDS ONLINE

3D изометрическая морская MMO ARPG в мире Эйдмар.

## Статус

Начальная разработка. Игровой прототип находится в подготовке. Готового APK и серверной MMO пока нет.

## Технологии

- Godot 4, GDScript
- Android, горизонтальная ориентация
- Изометрическая камера и гибридная бортовая артиллерия
- Серверно-авторитетная MMO в будущих этапах

## Разработка

Новые игровые функции создаются в отдельных ветках и проверяются перед слиянием с `main`.

## Документация

Концепция GDD v0.1–v0.5 подготовлена в ходе проектирования; её перенос в репозиторий запланирован отдельно.
